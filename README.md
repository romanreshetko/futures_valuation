# Предсказание движения цен на фьючерсы с использованием текстовых данных

Годовой проект магистерской программы ФКН НИУ ВШЭ, 2026/27 учебный год.

## О проекте

Цель проекта — построить модель, предсказывающую движение цен на фьючерсы, и сервис, предоставляющий интерфейс для использования модели, а также оценить, насколько текстовые данные улучшают качество прогноза по сравнению с моделями, обученными только на рыночных данных.

Основой служат классические ML-модели на табличных данных о ценах фьючерсов. Новостные тексты используются как дополнительный источник признаков для усиления этих моделей.

В работе рассматриваются ликвидные сырьевые фьючерсы и фьючерсы на металлы (золото, нефть, природный газ), так как на их цены текстовые новости влияют наиболее заметно.

## Данные

- Табличные данные: исторические котировки выбранных фьючерсов. Основной датасет, с него начинается работа.
- Текстовые данные: новости, связанные с выбранными инструментами. Собираются параллельно на первых этапах для использования в разведочном анализе и исследования влияния на стоимость фьючерсов.

Источники данных и глубина истории будут зафиксированы на этапе разведочного анализа.
